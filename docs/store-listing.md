# MyLight 应用市场上架资料

## 基本信息

- 应用名称：MyLight
- 包名：com.zhouhaoran.mylight
- 分类：摄影 / 图片编辑
- 当前版本：1.4-beta
- 一句话简介：轻量、实时、面向移动端的专业图片调色工具。

## 应用介绍

MyLight 是一款类似 Lightroom 的移动端图片编辑应用，支持滤镜、光线、色彩、HSL、曲线、裁剪、局部调整、历史记录、对比预览、批量导出和自定义滤镜。应用优先在本地完成图片处理，适合快速修图、调色和保存个人滤镜。

## 核心功能

- 相册图片导入与本地编辑
- 实时预览与长按对比原图
- 预设滤镜、自定义滤镜、上次修改记忆
- 光线、色彩、HSL、曲线、效果与局部调整
- 自由裁剪、固定比例裁剪、旋转和自动水平
- 历史记录、撤销、重做
- 批量导出当前效果
- 应用内检查更新
- 意见反馈入口

## 权限说明

- 网络访问：用于检查更新、下载更新包、提交意见反馈。
- 相册读取：用户主动选择图片后读取，用于本地编辑。
- 图片保存：用户主动保存时写入系统相册或指定位置。
- 安装未知应用：仅用于用户主动选择下载并安装 MyLight 更新包。

## 审核备注

MyLight 不会主动上传用户图片。图片处理主要在设备本地完成。意见反馈使用 GitHub Issue 页面，更新检查使用 GitHub 上的版本文件和 APK 下载地址。
