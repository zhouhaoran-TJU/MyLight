# MyLight 隐私政策

更新日期：2026-05-27

MyLight 是一款本地图片编辑应用。我们重视用户隐私，并尽量减少权限和数据收集。

## 权限使用

- 相册图片：仅在用户主动选择图片后读取，用于本地编辑和预览。
- 网络访问：用于检查版本更新、下载更新包、打开 GitHub 反馈页面。
- 保存图片：用户点击保存时，将编辑后的图片写入系统相册或用户选择的位置。
- 安装更新包：仅在用户主动选择下载并安装更新时使用。

## 数据处理

图片编辑过程主要在设备本地完成。MyLight 不会主动上传用户图片。

为了在应用进入后台后恢复编辑状态，应用会在本地私有目录缓存最近一次打开图片的预览副本和编辑参数。用户主动退出应用后，会清除本次会话缓存。

## 意见反馈

用户通过「意见反馈」提交建议时，会跳转到 GitHub Issue 页面。用户输入的反馈内容将由 GitHub 托管，并受 GitHub 的服务条款和隐私政策约束。

## 更新检查

应用会访问 GitHub 上的版本文件，用于判断是否存在新版本。用户确认后才会下载更新包并调起系统安装流程。
